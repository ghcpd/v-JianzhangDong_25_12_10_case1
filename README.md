# Project Environment & Test Runner

This repository includes generated files and scripts to set up a clean Python environment, install pinned dependencies, and run tests.

Generated files:
- requirements_backup.txt: backup of the original requirements.txt before automated updates.
- requirements.txt: updated, pinned dependencies suitable for Python 3.14.
- report.json: list of dependency issues found and recommended updates.
- .gitignore: updated to exclude .venv and logs.
- Dockerfile: containerized environment to run tests.
- setup.sh: create and populate .venv (Linux/macOS).
- run_test.sh: wrapper to run auto_test.py inside .venv (Linux/macOS).
- run_test.bat: wrapper for Windows.
- auto_test.py: orchestrates running tests using the .venv python and writes logs to logs/test_run.log.

Setup instructions (Linux/macOS):
1. Ensure Python 3.14 is available.
2. Run: ./setup.sh
3. Execute tests: ./run_test.sh

Setup instructions (Windows):
1. Ensure Python 3.14 is available in PATH.
2. Create venv: python -m venv .venv
3. Activate: .venv\Scripts\activate
4. Install deps: pip install -r requirements.txt
5. Run tests: run_test.bat

Docker (all platforms):
1. Build: docker build -t project-test .
2. Run: docker run --rm project-test

Using auto_test.py directly:
- Make sure .venv is present and populated.
- Run: .venv/bin/python auto_test.py (or .venv\Scripts\python.exe auto_test.py on Windows)

Logs:
- All test run outputs are appended to logs/test_run.log
